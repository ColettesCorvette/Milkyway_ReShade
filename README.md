# Milkyway_ReShade

Shader ReShade de post-traitement pour *Alien: Isolation*.

**Effets actuels :** étalonnage (contraste, teinte, vibrance), netteté AMD CAS, aberration chromatique (désactivée par défaut), vignette et grain de pellicule.

**Installation :** copier `Milkyway.fx` dans `reshade-shaders/Shaders/`, puis activer « Milkyway (Aliened) » dans ReShade. Pensez à désactiver le grain et l'aberration chromatique du jeu pour éviter les doublons.

D'autres effets seront ajoutés au fil du temps.
